# Users
This section is for users of ChatWS
1. Your private key is your second password TREAT IT LIKE A PASSWORD! DO NOT SEND IT TO ANYONE!
2. Your public key is for the server and users to send messages to you.
- Your public key __needs__ to be shared for users to send messages.
- You may be able to get it from your private key but it may be hard.
- You can also recover it from someone you have chatted with or the server admin. KEEP YOUR PUBLIC KEY SAFE!
